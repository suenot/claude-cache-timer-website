Claude keeps your context in the prompt cache for one hour. Miss it, and the next prompt writes the whole conversation again at full price.

01 / the clock

Warm for an hour.
Then full price.

A reply lands: the context is written to the cache and the hour starts.

  • 0m · reply, cache written
  • 50m · band turns amber
  • 55m · auto-compact, still warm
  • 60m · expired, full rewrite

02 / the band

Three colors.
One glance.

A single line above the prompt. It counts from the last model response, so every reply of a running turn resets it, and it refreshes every 15 seconds.

03 / auto-compact

Compact while
it is still warm.

When the session sits idle and the cache is 55 minutes old, the mod runs /compact itself. The summary request reads the cached prefix cheaply, and your next prompt pays for a short summary instead of the whole context.

01

Once per idle period

After a compact nothing more happens until you write again. An abandoned session is compacted at most once, never every hour.

02

Stays out of the way

Skipped while a turn runs, while Keep warm is on, when the cache has already expired, and when the context is under 30k tokens.

03

Skip when you are done

Finished the task and will not come back? Press Skip auto-compact and spend nothing. The skip lasts until your next message.

04 / keep warm

Out for lunch.
Cache stays warm.

Press Keep warm 3h, 6h or 12h. When the cache is 50 minutes old and no turn is running, the mod sends one tool-less fork over the transcript. It reads the cached prefix and restarts the hour. Pick a window:

7pings in the window
6h 50mcache cold again at
3failed pings in a row stop it

Each ping re-reads the context from the cache, so it costs tokens at the cache-read rate. Warming stops by itself at the end of the window, when a ping finds the cache cold, or after /clear.

05 / install

One line.
Nothing to configure.

in a Claude Code session 
/plugin install cache-timer
  --marketplace suenot/claude-cache-timer
from a shell 
claude plugin install cache-timer
  --marketplace suenot/claude-cache-timer
in the desktop app

Click + next to the prompt box, then Plugins, Add marketplace with suenot/claude-cache-timer, then Add plugin.

Source on GitHub ↗ TTL is one constant: set TTL_MS to 5 minutes if your session uses the short cache.
